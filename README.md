# Orión_forge 🌌✨

**Orión_forge** es un mini entorno web inspirado en Blender, diseñado para mostrar cómo las **funciones matemáticas** pueden convertirse en animaciones y modelos 3D interactivos.  
Este proyecto combina creatividad, estética kawaii y matemáticas aplicadas al modelado digital.

---

## 🚀 Características principales
- Animaciones basadas en **[funciones trigonométricas](ca://s?q=Uso_de_seno_y_coseno_en_modelado_3D)** (seno y coseno).
- Movimiento y escalado con **[funciones lineales](ca://s?q=Funciones_lineales_en_modelado_3D)**.
- Generación de curvas y superficies mediante **[gráficos paramétricos](ca://s?q=Gráficos_paramétricos_en_modelado_3D)**.
- Interfaz visual sencilla y amigable para estudiantes y creadores.
